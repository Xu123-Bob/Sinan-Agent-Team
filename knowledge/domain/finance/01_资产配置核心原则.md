# 资产配置核心原则

## 一、配置的本质

资产配置不是"选哪个涨得好"，而是**在不确定性中管理风险与收益的平衡**。
核心问题永远只有三个：
1. 我有多少钱、多久不用？（期限约束）
2. 我能承受多大回撤？（风险承受力）
3. 我希望达成什么目标？（收益目标）

配置方案必须同时满足这三个约束，任何只谈收益、不谈风险与期限的方案都是无效的。

## 二、五大核心原则

### 原则 1：风险优先于收益
- 先确定"最多能亏多少不失眠"，再倒推能承受的收益目标
- 不是"我想赚 20% 所以买高风险资产"，而是"我能承受 20% 回撤，因此可以配 X% 权益"
- **风险预算（Risk Budgeting）** 比收益预算更重要

### 原则 2：分散不等于多买
- 买 10 只科技股 ≠ 分散，仍然是单一因子暴露
- 真正的分散要求**低相关性**：不同资产类别（股/债/商品/现金）、不同地域、不同行业、不同因子
- 相关性在危机时会趋同（correlation goes to 1），所以分散只能**降低**而非消除风险

### 原则 3：期限决定资产
| 资金可用期限 | 适配资产 |
|---|---|
| < 1 年 | 货币基金 / 短债 / 存款 |
| 1-3 年 | 短债 / 中短债 / 保守混合 |
| 3-5 年 | 混合型 / 平衡型 |
| 5-10 年 | 权益类 / 目标日期基金 |
| > 10 年 | 权益类 / 长期股权 |

**核心逻辑**：短期资金配高波动资产 = 用确定性换不确定性，是配置失败的头号原因。

### 原则 4：再平衡是纪律，不是预测
- 定期（如每年）或阈值触发（如偏离目标 5%）时再平衡
- 再平衡的本质是**强制低买高卖**，克服追涨杀跌的人性
- 不预测市场，只执行规则

### 原则 5：成本是确定的负收益
- 管理费、托管费、交易佣金、申购赎回费、税，全部确定侵蚀收益
- 长期看，1% 的年化成本差异在 20 年后会吃掉约 20% 的累计收益
- 优先选择低成本指数工具，除非主动管理有持续 alpha 的证据

## 三、配置流程（五步法）

1. **明确目标与约束**
   - 目标：退休 / 教育金 / 购房 / 财富保值 / 传承
   - 期限：何时用钱
   - 金额：一次性 vs 定投
   - 流动性需求：随时可取的比例

2. **评估风险承受力**
   - 客观能力：收入稳定性、负债、家庭责任、应急金是否充足
   - 主观意愿：历史最大可接受回撤、失眠阈值
   - 二者取**较低值**作为约束

3. **确定战略资产配置（SAA）**
   - 大类资产比例：股 / 债 / 商品 / 现金 / 另类
   - 参考经典模型（见 03_经典配置模型.md）
   - 一旦确定，作为长期锚点

4. **战术调整（TAA，可选）**
   - 在 SAA 基础上，根据估值、宏观做小幅偏离（通常不超过 ±10%）
   - 无专业能力者，建议不做 TAA，直接执行 SAA

5. **执行 + 再平衡**
   - 分批建仓或定投，避免择时
   - 建立再平衡规则并严格执行

## 四、常见误区

| 误区 | 真相 |
|---|---|
| "分散就是多买几只基金" | 同质化基金无分散效果 |
| "高风险才有高收益" | 高风险≠高收益，只是收益分布更宽 |
| "我看好某行业所以重仓" | 集中押注是投机，不是配置 |
| "等市场跌了再买" | 择时长期看输给纪律 |
| "过去 3 年涨得好就是好资产" | 业绩不代表未来，看长期与风险调整后收益 |
| "配置一次就一劳永逸" | 需定期再平衡与生命周期调整 |

## 五、判断一个配置方案是否合格（检查清单）

- [ ] 是否明确了期限约束？
- [ ] 是否评估了风险承受力？
- [ ] 大类资产是否覆盖 3 类以上（股/债/现金为最低要求）？
- [ ] 单一资产占比是否超过 50%？（超过需有充分理由）
- [ ] 是否有再平衡规则？
- [ ] 是否考虑了极端情景（-30% 回撤时是否还能持有）？
- [ ] 成本是否可控（综合费率 < 1%）？
- [ ] 是否有流动性储备（应急金 3-6 个月）？
