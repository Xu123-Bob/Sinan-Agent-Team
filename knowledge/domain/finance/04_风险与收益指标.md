# 风险与收益指标

## 一、收益指标

### 1. 累计收益率
- 公式：(期末价值 - 期初价值) / 期初价值
- 缺陷：不考虑时间、不考虑波动

### 2. 年化收益率（CAGR）
- 公式：(期末/期初)^(1/年数) - 1
- 用途：跨期比较
- 注意：**年化 ≠ 每年都赚这么多**，某年可能 -30%

### 3. 超额收益（Alpha）
- 相对基准的超额：组合收益 - 基准收益
- 需扣除风险暴露后计算，否则可能是 beta 伪装成 alpha

## 二、风险指标

### 1. 波动率（标准差）
- 衡量收益的离散程度
- 年化波动率 = 日波动率 × √252
- 经验值：
  - 货币基金 < 1%
  - 短债 1-3%
  - 中长期债 3-8%
  - 混合型 8-15%
  - 权益型 15-25%
  - 单一行业 25-40%

### 2. 最大回撤（Max Drawdown）
- 从历史最高点到最低点的跌幅
- **比波动率更直观**：直接反映"最坏情况能亏多少"
- 经验值：
  - 货币基金：≈ 0
  - 债券基金：-3% 至 -10%
  - 混合型：-15% 至 -30%
  - 权益型：-30% 至 -60%
  - 单一行业/主题：-50% 至 -80%

### 3. 夏普比率（Sharpe Ratio）
- 公式：(组合收益 - 无风险利率) / 波动率
- 含义：每承担 1 单位波动，获得多少超额收益
- 经验值：
  - < 0.5：差
  - 0.5-1.0：可接受
  - 1.0-2.0：优秀
  - > 2.0：极优秀（警惕过度优化/幸存者偏差）

### 4. 卡玛比率（Calmar Ratio）
- 公式：年化收益 / 最大回撤
- 含义：每承担 1 单位最大回撤，获得多少年化收益
- 更适合评估"持有体验"

### 5. 索提诺比率（Sortino Ratio）
- 类似夏普，但只考虑下行波动
- 更适合非对称收益分布的资产

### 6. Beta
- 相对市场的敏感度
- Beta = 1：与市场同步；> 1：涨跌更猛；< 1：更稳
- 用途：判断组合的"市场暴露度"

## 三、风险承受力评估

### 客观能力（Capacity）

| 因素 | 高能力 | 低能力 |
|---|---|---|
| 收入稳定性 | 稳定、有增长 | 波动、不确定 |
| 应急金 | 12 个月以上 | 不足 3 个月 |
| 负债 | 无高息负债 | 有房贷压力 |
| 家庭责任 | 单一、无抚养压力 | 多孩、赡养老人 |
| 投资期限 | 10 年以上 | 3 年以内 |

### 主观意愿（Willingness）

- **失眠测试**：组合跌多少会睡不着？
- **模拟测试**：假设明天组合跌 30%，你会：加仓 / 持有 / 割肉？
- **历史检验**：过去遇到大跌时你的实际反应

### 综合判定

**取客观能力与主观意愿的较低值**作为风险约束。

例如：
- 客观能力：可承受 -40%
- 主观意愿：只能承受 -20%
- → **实际约束：-20%**

### 风险等级对照

| 等级 | 最大回撤容忍 | 建议权益比例 |
|---|---|---|
| 保守型 | < 5% | 0-20% |
| 稳健型 | 5-15% | 20-40% |
| 平衡型 | 15-25% | 40-60% |
| 成长型 | 25-35% | 60-80% |
| 进取型 | > 35% | 80-100% |

## 四、风险调整后收益的判断

**只看收益是致命的**。比较两个方案：

- 方案 A：年化 15%，波动 30%
- 方案 B：年化 10%，波动 10%

**A 的夏普比率 = (15-3)/30 = 0.4**
**B 的夏普比率 = (10-3)/10 = 0.7**

→ **B 更优**。因为 A 每单位风险获得的超额收益更低，且实际持有体验差（大回撤容易拿不住）。

## 五、常见指标误用

| 误用 | 正确做法 |
|---|---|
| 只看 1 年收益 | 至少看 3-5 年，最好看 10 年 |
| 只比收益不比风险 | 用夏普/卡玛比率 |
| 幸存者偏差 | 看全部历史基金，不只活下来的 |
| 过度回测 | 警惕 curve fitting，看样本外表现 |
| 忽略税费 | 税后收益才是真实收益 |
| 用短期波动代表长期风险 | 长期风险是"目标未达成"，不是短期波动 |
