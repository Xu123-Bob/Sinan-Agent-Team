# 主要资产类别特征

## 一、权益类（股票/权益基金）

| 维度 | 特征 |
|---|---|
| 长期收益 | 最高（全球长期年化约 7-10%） |
| 波动性 | 高（年化波动 15-25%） |
| 最大回撤 | 历史极端 -50% 至 -70% |
| 相关性 | 与债券低相关/负相关；与其他权益高相关 |
| 期限适配 | 5 年以上 |
| 核心风险 | 估值泡沫、盈利下滑、地缘政治 |

**细分**：
- 宽基指数（沪深300、标普500）：分散度高，适合核心配置
- 行业/主题基金：波动更大，适合卫星配置（≤10%）
- 个股：非专业投资者不建议超配

## 二、固定收益类（债券/债券基金）

| 维度 | 特征 |
|---|---|
| 长期收益 | 中低（年化 2-5%） |
| 波动性 | 低（年化波动 2-8%，视久期） |
| 最大回撤 | 通常 -5% 至 -15%（利率剧烈变动时） |
| 相关性 | 与股票低相关/负相关（危机时避险） |
| 期限适配 | 1-10 年 |
| 核心风险 | 利率风险（久期）、信用风险、通胀侵蚀 |

**细分**：
- 利率债（国债、政金债）：信用风险低，利率敏感
- 信用债（企业债）：信用利差，需关注违约风险
- 短债/货币：久期短，波动小，接近现金

**久期概念**：久期越长，对利率越敏感。利率上行 1%，久期 5 年的债券约跌 5%。

## 三、现金类（货币基金/存款/短债）

| 维度 | 特征 |
|---|---|
| 收益 | 极低（接近政策利率） |
| 波动性 | 极低 |
| 作用 | 应急金、等待机会、降低组合波动 |
| 建议比例 | 3-6 个月生活费作为应急金，独立于投资组合 |

## 四、商品类（黄金/原油/农产品）

| 维度 | 特征 |
|---|---|
| 作用 | 抗通胀、危机对冲、分散 |
| 黄金 | 与股债低相关，危机时避险，无现金流 |
| 建议比例 | 5-10% 作为组合分散器 |
| 风险 | 无收益（无利息/股息），波动大 |

## 五、另类资产（REITs/私募/对冲基金）

| 维度 | 特征 |
|---|---|
| 作用 | 进一步分散、追求非相关收益 |
| REITs | 不动产收益，与股债相关性中等 |
| 私募/对冲 | 门槛高、流动性差、费用高 |
| 建议 | 合格投资者才考虑，普通投资者可略过 |

## 六、资产间相关性（长期近似）

| | 股 | 债 | 黄金 | 现金 |
|---|---|---|---|---|
| **股** | 1.00 | -0.1~0.3 | -0.1~0.2 | 0 |
| **债** | -0.1~0.3 | 1.00 | 0~0.3 | 0 |
| **黄金** | -0.1~0.2 | 0~0.3 | 1.00 | 0 |
| **现金** | 0 | 0 | 0 | 1.00 |

> ⚠️ 相关性在**危机时会趋同**。2008、2020 年 3 月股债同跌出现过。分散只能降低风险，不能消除。

## 七、不同宏观环境下的资产表现（经验规律）

| 环境 | 股票 | 债券 | 黄金 | 现金 |
|---|---|---|---|---|
| 增长↑ 通胀↓（金发女孩） | 强 | 中 | 弱 | 弱 |
| 增长↑ 通胀↑（过热） | 中 | 弱 | 强 | 中 |
| 增长↓ 通胀↓（衰退） | 弱 | 强 | 中 | 强 |
| 增长↓ 通胀↑（滞胀） | 弱 | 弱 | 强 | 弱 |

**用途**：帮助判断当前配置是否过度依赖单一环境假设。

## 八、选择工具的优先级

1. **宽基指数 ETF**（成本低、透明、分散好）
2. **优质主动基金**（有长期 alpha 证据，费率合理）
3. **个股/主题**（仅作为卫星仓位，≤10%）
4. **另类**（合格投资者才考虑）

**核心原则**：先解决"资产配置对不对"，再解决"具体买哪只"。90% 的长期收益来自资产配置，而非个券选择。
