# 知识库（只读）

## 用途

这里存放**组织公共知识**，供 6 个智能体共享阅读。
所有 Agent 在生成前会读取本目录内容作为**参考上下文**。

## ⚠️ 重要约束

- **本目录对所有 Agent 只读**，任何 Agent 都无法写入、修改、删除本目录内的任何文件。
- 所有输出（策略 / Rubric / 辩论记录）都会落到 `outputs/`（或 `SINAN_OUTPUT_DIR`），**绝不会回写这里**。
- 代码层通过 `safe_io.safe_write` 强制校验，写入本目录会直接抛 `PermissionError`。

## 适合放什么

- ✅ 公司品牌 / 用语规范
- ✅ 领域行业标准 / 政策红线
- ✅ 内部 SOP / 流程文档
- ✅ 可复用的策略模板
- ✅ 历史优秀案例（脱敏后）
- ✅ 产品参数 / 规格表

## 不适合放什么

- ❌ 明文密钥 / 密码
- ❌ 客户隐私数据
- ❌ 与本系统无关的临时文件
- ❌ 大型二进制（图片/视频），会浪费 token 且无实际价值

## 文件格式支持

- `.md` `.txt` — 直接读取（推荐）
- `.csv` `.xlsx` `.xls` — 解析为 Markdown 表格
- `.docx` `.pptx` — 提取文本
- `.yaml` `.yml` `.json` — 原样读取
- 图片 / 视频 / 压缩包 — 自动忽略

## 体量控制

- 单文件超过 8000 字符自动截断
- 目录总内容超过 20000 字符（约 10k token）自动截断
- 按优先级截断：文档 > 表格 > 其他
- 可通过 `.env` 调整：`SINAN_KNOWLEDGE_MAX_CHARS=30000`

## 物理加固（可选）

Linux / macOS 上可执行：

```bash
chmod -R a-w knowledge/
```

开启物理只读，即使代码有 bug 也写不进去。
